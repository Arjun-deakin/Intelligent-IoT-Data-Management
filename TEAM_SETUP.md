# Team Setup

## Purpose

This file explains how to run the Intelligent IoT Data Management Platform with the engineering analytics stack enabled.

## Prerequisites

- Docker Desktop installed and running
- WSL integration enabled if using WSL
- Ports available:
  - `3000`
  - `3001`
  - `5000`
  - `5001`
  - `5173`
  - `5432`
  - `8081`
  - `9090`
  - `9104`

## Start The Full Stack

Run from the repository root:

```bash
docker compose up --build -d
```

## Stop The Stack

```bash
docker compose down
```

To remove the PostgreSQL volume too:

```bash
docker compose down -v
```

## Services

- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:3000`
- Backend health: `http://localhost:3000/health`
- Backend metrics: `http://localhost:3000/metrics`
- Archived analytics service: `http://localhost:5000`
- Correlation alert service: `http://localhost:5001`
- Grafana: `http://localhost:3001`
- Prometheus: `http://localhost:9090`
- cAdvisor: `http://localhost:8081`
- Docker service exporter: `http://localhost:9104/metrics`

## Quick Validation

Run:

```bash
curl http://localhost:3000/health
curl http://localhost:3000/metrics
curl http://localhost:9090/-/healthy
```

Expected:

- backend health returns `200 OK`
- backend metrics endpoint returns Prometheus-formatted metrics
- Prometheus health returns healthy

## Monitoring Scope

The stack currently monitors:

- backend API metrics
- DB health and DB query metrics
- ThingSpeak ingestion metrics
- frontend telemetry events
- frontend route mismatch metrics
- container CPU, memory, up/down, and restart metrics
- auxiliary service metrics for:
  - `correlation-alert`
  - `archived-analytics`

## Prometheus Alert Rules

Implemented rules:

- `BackendUnavailable`
- `HighApiP95Latency`
- `FrontendRouteMismatchDetected`
- `ThingSpeakPollingFailures`
- `DatabaseUnhealthy`

## Known Notes

- `Frontend / Integration Mismatch` depends on browser telemetry events being generated by the frontend.
- `Container Restarts` is based on the Docker service exporter and should now be stable across stack recreations.
- `ThingSpeak` metrics depend on the polling interval configured in the backend environment.

## Troubleshooting

### Docker Desktop instability on Windows

If Docker Desktop behaves unexpectedly:

1. Quit Docker Desktop
2. Run in PowerShell as Administrator:

```powershell
wsl --shutdown
```

3. Start Docker Desktop again

### Grafana shows stale dashboard panels

```bash
docker compose restart grafana
```

Then hard refresh the browser:

```text
Ctrl + Shift + R
```

### Prometheus is not scraping targets

Check:

```bash
docker compose ps
docker compose logs prometheus --tail 100
```

### Backend is unhealthy

Check:

```bash
docker compose logs backend --tail 100
curl http://localhost:3000/health
```

### Rebuild everything cleanly

```bash
docker compose down -v
docker compose up --build -d
```
